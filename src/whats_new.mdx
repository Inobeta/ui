# What's new

## Migration to app.config

In this release, the library has been updated to Angular 19, adopting the new `app.config` approach and relegating support for `app.module` to a minimal level.
It is strongly recommended to migrate to `app.config` as soon as possible to take full advantage of the latest features and to ensure compatibility with future updates.

Additionally, the general trend will be to increasingly adopt standalone components.
In an initial phase, we will continue to use modules as mere collectors;
however, they will eventually be deprecated and removed.
We recommend using standalone components as they become available to align with this transition and ensure smoother future migrations.
