# What's new

## Maintenance release

In this release, there are no substantial changes compared to previous versions. However, we’ve introduced some improvements to enhance functionality and flexibility in specific use cases:

- **Symbol Support for Numeric Columns in `ibKaiTable`**: Numeric columns in `ibKaiTable` now support symbols, allowing for a richer and more versatile representation of numerical data.
- **Exposed Asset Path for `ibTranslate`**: The asset path for `ibTranslate` is now exposed, providing greater control and customization when managing translation assets.

These updates aim to provide a more seamless user experience while maintaining compatibility with existing functionality.
