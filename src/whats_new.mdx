# What's new

## Migration to app.config

In this release, the library has been updated to **Angular 20**.


## Node.js requirement

Starting with this release, it is recommended to use **Node.js 22.19** or higher to ensure full compatibility and stability with Angular 20 and upcoming versions of the library.
